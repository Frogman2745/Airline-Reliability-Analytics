# Portfolio upload guide

## Suggested project title

Airline Reliability Analytics | BTS Data, SQL, Python, Power BI

## Short description

Built a reproducible airline reliability analysis from official U.S. Bureau of Transportation Statistics marketing-carrier data for January and February 2025. Reconciled 1,158,590 flight rows into 20 carrier-month and 17,291 directional carrier-route-month records, queried weighted on-time arrival rates in SQLite, and created an interactive offline dashboard plus an editable Power BI report with named airlines and an airline-filtered route explorer. The analysis is descriptive; the two-month sample does not establish trends or causes.

## Resume bullet

- Built a Python, SQL, and Power BI workflow for 1.16M public BTS flight records, reconciling 20 carrier-month and 17,291 directional route-month aggregates and reporting weighted on-time rates by airline and route.

## Upload files

- Upload `Airline_Reliability_Portfolio.zip` as the complete source and report package when file attachments are supported.
- Link or upload `Airline_Reliability_Dashboard.html` for a browser-viewable interactive artifact.
- Use `PORTFOLIO_CASE_STUDY.md` for the written project explanation and `RESULTS.md` for verified metrics.
- Open `Airline_Reliability_2025.pbix` with Power BI Desktop to edit the report. Its refresh sources are local CSV paths and may need repointing after extraction.

Do not describe this project as a live pipeline, a PostgreSQL/dbt implementation, a full-year trend, or an operational improvement to an airline. The source records are public; the portfolio project and analysis are independent work.
